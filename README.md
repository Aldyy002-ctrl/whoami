# Muhammad AldiAnsyah Portfolio

Portofolio personal Muhammad AldiAnsyah yang dibangun dengan Next.js dan dioptimalkan untuk desktop, mobile, serta deployment di Vercel.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```
